# Git 学习记录（一）

## 一、什么是 Git 和 GitHub

> 简单概括：**Git** 负责版本控制，**GitHub** 提供在线托管和协作环境。

### Git

Git 是一个版本控制工具，主要运行在本地。

它可以记录项目的修改历史，让我们能够：

- 保存不同版本
- 查看历史修改
- 创建分支
- 合并代码
- 在出现问题时恢复之前的版本

### GitHub

GitHub 是一个基于 Git 的在线开发平台。

除了存储 Git 仓库，还可以用于：

- 项目协作
- Pull Request
- Code Review
- Issue
- 项目展示
- 开源项目管理
